# Лекция «Хроническая сердечная недостаточность»

Полная академическая лекция (≈ 55 тыс. слов, 196 страниц A4) для студентов и специалистов, написанная по 30-разделному плану промпта v2.0: определение и терминология, эпидемиология, этиология, патогенез, классификации, клиника, диагностика, дифференциальный диагноз, прогноз, профилактика, лечение (базисная терапия, диуретики, дополнительная фармакотерапия, ХСНсФВ, этиотропные подходы), коморбидность, особые группы, устройства и хирургия, декомпенсация, реабилитация, организация наблюдения, продвинутая ХСН, паллиативная помощь, доказательная база, дискуссионные вопросы, практическое значение, заключение с 35 итоговыми вопросами, глоссарий и источники.

## Файлы

| Путь | Назначение |
|---|---|
| `Хроническая_сердечная_недостаточность_Лекция.pdf` | **Итоговая лекция** с встроенными схемами (32 рис.) и таблицами (48 табл.), оглавлением и нумерацией страниц |
| `ЛЕКЦИЯ-полный-текст.md` | Полный текст лекции одним Markdown-файлом (генерируется сборкой) |
| `лекция/00…32-*.md` | Исходные главы (по разделам плана) |
| `СЛУЖЕБНОЕ-подготовка-и-самопроверка.md` | Служебные блоки 🛠️ ПОДГОТОВКА и ✅ САМОПРОВЕРКА (вне PDF) |
| `build-tools/` | Сборка: `build.mjs` (markdown-it + KaTeX + Mermaid → Chromium → PDF, двухпроходное оглавление), `style.css`, `title.html`, шрифты |

## Сборка PDF

```bash
cd build-tools
npm install
node build.mjs
```

Требуется Node.js ≥ 20. Сборка печатает число страниц, заголовков и ошибок рендеринга схем.
